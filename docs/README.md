# UmucoPulse — public GitHub Pages prototype

Community-centred demo for preserving, sharing and connecting around Rwandan cultural heritage.

**Live URL:** https://umutoni2.github.io/UmucoPulse/

Pages: Home, Discover (six cultural areas), Creators, public creator profiles, Voices, Projects, Opportunities, About, Contact, Register/Login, contributor dashboard, My Cultural Profile, Admin.

## Demo accounts
- Administrator: `admin@umucopulse.org` / `Umuco123!`
- Contributor: `sylvie@umucopulse.org` / `Story123!`

Register a contributor, then build a public cultural profile. Seeded creator cards are **fictional demo / prototype** profiles.

## What is stored where
All data lives in **this browser’s localStorage**. It is not a real server. Media “uploads” store file **names** only. Passwords are for prototype login only — this is not production security.

Language switching (EN / RW / FR) currently changes selected homepage labels, not every paragraph.

Opportunities are labelled **demo / prototype / illustrative**. No government endorsement or real institutional partnership is claimed.

If GitHub still shows an old site: **Settings → Pages →** branch `master` or `main`, folder **/docs**.
